## Что в архиве

```
public/                                ТОЛЬКО новые и изменённые файлы — положить поверх public/ в репозитории
  <slug>/index.html, <lang>/<slug>/    40 новых страниц (5 статей × 8 языков)
  guides/, <lang>/guides/              /guides/ на 8 языках: 8 карточек (5 новых + №3 + №2 + №1)
  sitemap.xml                          +56 URL с hreflang: 5 новых статей и №2, №3 (их в карте сайта не было)
build-art-<slug>/                      сборка каждой статьи, в формате статьи №3
  md/<lang>.md                         исходные тексты (источник правды)
  article-en.html, template-art.html, content/<lang>.json, render_art.py, check_units.py
tools-batch/
  make_batch.py                        md → article-en.html + template-art.html + content/*.json для всех 5 статей
  kit/                                 шаблоны render_art.py и check_units.py для статей
  integrate_batch.py                   карточки на /guides/ + sitemap.xml (повторный запуск безопасен)
  validate_all.py                      проверка всего сайта: лендинг, /guides/, все 8 статей
```

## Как встроить

Вариант А — просто залить: скопировать содержимое `public/` из архива поверх `public/` в репозитории.

Вариант Б — пересобрать из исходников (из корня репозитория; нужна папка `build-art-christmas-markets-near-colmar/`, из неё берётся оформление сайта):

```
cp -r build-art-* tools-batch <корень репозитория>
python3 tools-batch/make_batch.py
for s in is-colmar-worth-visiting best-time-to-visit-colmar how-to-get-to-colmar where-to-stay-in-colmar colmar-parking; do
  python3 build-art-$s/check_units.py && python3 build-art-$s/render_art.py
done
python3 tools-batch/integrate_batch.py
python3 tools-batch/validate_all.py
```

Проверено на свежей копии репозитория: результат совпадает с `public/` в архиве побайтно.

Правка текста: меняете `build-art-<slug>/md/<lang>.md` → `make_batch.py` → `render_art.py` нужной статьи. Структура всех 8 языков должна совпадать с английской: скрипт остановится и покажет место, если где-то лишний или недостающий абзац, пункт списка или ссылка.

## Что сознательно не трогали

- **Статьи №1–№3 и лендинг** не изменены. Поэтому в выпадающем меню «Путеводители» и в подвале на всех страницах (включая новые) по-прежнему только три рождественские статьи.
